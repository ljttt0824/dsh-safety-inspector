## v1.0.1 修复（桌面版实测反馈）

桌面版装上后暴露了三个问题，均已修复并用 `test/cdp-fixes.mjs` 回归（7/7）：

| 现象 | 根因 | 修复 |
|---|---|---|
| 每条回答都显示「无工具调用」 | 一轮的 **tool/call 分散在多个 step**，而 assistant 回复落在**最后一个纯文本 step**；浮层只取该 step 的调用，必然为空 | `chainOf` 新增 `turnGroups` 聚合；浮层/Inspector 按**轮次**取全部调用，纯文本步自动展开整轮 |
| 风险分永远 0 | `score = max(0, 100 - 扣分)`，任意真实会话扣分 >100 立即贴地 | 改为饱和曲线 `round(10000 / (100 + 扣分))`：干净 100、中等 60 上下、严重 12–30，不再有"0 分=严重" |
| 严重/高/中 点不进去 | 概览的数字是纯展示；发现列表点击只更新内联详情，用户停在列表中部看不到 | 严重/高/中/低改为**可点筛选**；点任意发现直接打开详情浮层（证据 + 关联调用 + 整轮链路） |

实测（会话 `e3a7ff48`，313 次调用）：风险分 `0 → 12`；消息深链显示 `T1 · 56 次调用 · 49 步 · 1 失败`；点「严重」筛出 `11` 条；点发现打开浮层。
`18/18` 接口断言、`13/13` 浏览器断言、`15/15` 单元用例、`7/7` 回归断言全通过。

## v1.1.0 通俗版与 AI 分析

针对「看不懂代码」的反馈，新增两层，并把 token 花销讲清楚。

| 层 | 产出 | 花费 |
|---|---|---|
| 通俗摘要（默认） | 工具用途、访问数据、请求/结果一句话、风险等级与依据 | 0 token（`lib/narrate.js` 本地规则） |
| 原始数据（开关） | 完整参数/结果 JSON | 0 token |
| AI 详细分析（按钮） | 逐条点评 + 整轮结论 | 按轮调用，结果按 payload 哈希缓存 |

同时修掉三个真实缺陷：

1. **`useCallback` 落在早退分支之后** → React hook 数量在「加载中→有数据」时变化，执行链整块崩溃（这就是「看不到步骤」的直接原因）。
2. **大轮次输出被 2048 截断** → JSON 半截解析失败、返回 0 条点评。改为 4096 预算，失败时对半拆分重试并合并。
3. **风险分贴地** → 改饱和曲线（v1.0.1 已修，本轮沿用）。

另外：默认选中「有调用的那一步」或「失败的那一步」，不再停在纯文本步；「只看失败」可过滤；AI 按钮旁明确标注消耗 token。

实测（deepseek-flash，本机真实会话 `8aa373c4`）：

|---|---|---|---|---|
| T8 | 19 | ≈2,711 token / 9,186 字符 | 1,687 token | 8.5s |
| T7 | 39 | ≈5,407 token / 18,671 字符 | 3,299 token | 14.7s |

回归：`18/18` 接口断言、`7/7` 通俗版浏览器断言（`test/cdp-nl.mjs`）、`15/15` 单元用例。
